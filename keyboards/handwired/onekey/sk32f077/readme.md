# 3Think SK32F077 onekey

* Supported Hardware: 3Think SK32F077 (register-compatible with the STM32F072, Mentor/MUSB "musbfsfc" USB controller)

To trigger keypress, short together pins *B4* and *B5*.

This board is used to validate the SK32F0xx platform integration (SK32F077 MCU, GENERIC_SK32_F077 board).
USB is intentionally not enabled in this demo build.
